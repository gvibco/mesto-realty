# Дизайн: минималистичный hero, комиссия за аренду, ИИ на главной, админы и редактор текстов

Дата: 02.11.2026. Статус: утверждён пользователем.

Проект: «Место Бизнес» — B2B-площадка коммерческой недвижимости
(Node.js 22 + Express 5 + PostgreSQL, фронтенд на чистом JS без фреймворков,
SPA-роутинг в `public/js/app.js`, стили `public/styles.css`).

## 1. Поля суммы без спиннера

У всех `input[type="number"]` (бюджет в поиске, фильтры каталога, цена и
площадь в редакторе, характеристики) скрываются нативные стрелки:
`appearance: textfield` и `::-webkit-inner-spin-button/::-webkit-outer-spin-button
{ appearance: none; margin: 0 }`. Разметка и валидация не меняются.

## 2. Комиссия за аренду — 40% месячной ставки

- Продажа: 1% от цены объекта.
- Аренда: 40% от месячной ставки, разово при сделке. Это ниже типичных
  50–100% у агентств коммерческой недвижимости.
- Константы комиссии живут в `public/js/core.js`
  (`COMMISSION = { sale: 0.01, rent: 0.4 }`), используются в карточке объекта.
- В карточке объекта для аренды появляется строка
  «Комиссия сервиса: 40% месячной аренды — X ₽».
- Все тексты «аренда — бесплатно», «комиссии нет» заменяются. Размещение
  объявлений остаётся бесплатным.
- Обновляются: `index.html` (title, description), `DEFAULT_CONTENT`,
  hero, блок комиссии, README и профильные docs.

- Плавающая кнопка `#assistant` скрывается только на главной; на остальных

## 5. Заголовки: минимализм + 4U

Формула 4U: Useful, Urgent, Unique, Ultra-specific. Конкретика уходит в
поддерживающую строку, заголовок — короткий (2–4 слова).

- H1: «Помещение для бизнеса — за 48 часов» (2 строки, шрифт
  `clamp(34px, 4vw, 48px)` вместо `clamp(42px, 4.7vw, 64px)`).
- Подзаголовок: «Офисы, склады и торговые площади от собственников.
  Комиссия только при сделке: 1% с покупки, 40% аренды.»
- Секции:
  - «Под задачу бизнеса»;
  - «Новые объекты» / «Свежие предложения с ценой и площадью»;
  - «Выберите город» / «Объекты с ценой и площадью в вашем городе»;
  - «Как мы зарабатываем» / «Комиссия только при сделке: 1% с покупки,
    40% аренды»;
  - «Разместите объект бесплатно» / «Получайте обращения от компаний»;
  - каталог: «Коммерческая недвижимость» / «Офисы, склады и торговые
    площади — фильтры по цене и площади»;
  - карточка: «Об объекте» (остаётся коротким).

## 6. Иконка переключения темы

Вместо эмодзи 🌙/☀️ — две inline SVG-иконки (солнце и луна, stroke

Кнопка сохраняет размеры 44×44 и состояния hover/focus.

## 7. Админ-панель

### 7.1 Назначение админов

- Миграция `007_admins.sql`: `users.is_admin BOOLEAN NOT NULL DEFAULT false`.
- Админ = `users.is_admin = true` **или** email совпадает с `ADMIN_EMAIL`
  (бутстрап-админ).
- `isAdminUser`, `GET /api/auth/session`, `POST /api/auth/login`,
  `POST /api/auth/register` учитывают флаг из БД.
- `GET /api/admin/users` возвращает `admin`.
- `PATCH /api/admin/users/:id` принимает `{ blocked?, admin? }`:
  - нельзя менять собственный флаг админа (422);
  - нельзя снять права с `ADMIN_EMAIL`-аккаунта (422);
  - блокировка себя по-прежнему запрещена.
- В списке пользователей: бейдж «Админ», кнопки «Назначить админом» /
  «Снять права».

### 7.2 Редактирование маркетинговых текстов

- Реестр `CONTENT_FIELDS` в `server/content-fields.js`:
  `{ key, group, label, multiline, max }`. `DEFAULT_CONTENT` собирается из
  реестра. Охват: главная (hero, поиск/ИИ, категории, объекты, города,
  комиссия, баннер), каталог, карточка объекта, авторизация, подвал,
  SEO title/description.
- Функциональные подписи полей, кнопок и ошибки валидации остаются в коде.
- `GET /api/content` — плоские значения (контракт сохраняется).
- `GET /api/admin/content-fields` — группы и подписи для автоформы.
- `PUT /api/admin/content` — полная замена, zod по каждому ключу
  (`trim`, `min`, `max`, `strict`).
- Фронтенд: `public/js/content.js` с `loadContent()`, `contentValue()`,
  `applyContent(root)`. Элементы размечаются `data-content="key"`.
  `document.title` и `meta[name=description]` обновляются из
  `metaTitle` / `metaDescription`.
- Админ-форма генерируется по группам из `/api/admin/content-fields`,
  сохраняет все ключи одним PUT.

## 9. Проверка и деплой

1. `quality-reviewer` аудит изменений, исправление BLOCKER/IMPROVEMENT.
2. `npm run preflight`.
3. `git push origin main` → сборка Dockhost `techeco`.
4. `npm run verify:live` (главная, комиссия, ИИ, тема, админка).
5. Повторный аудит `quality-reviewer`.

## Ограничения

- Биллинга нет: 40% — справочная ставка в текстах и карточке.
- Полностью все строки интерфейса не редактируются (осознанный объём).
- Пароли, телефоны и приватные поля в контент не попадают.
