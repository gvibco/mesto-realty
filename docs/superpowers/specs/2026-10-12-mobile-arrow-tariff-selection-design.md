# Дизайн: стрелки на мобильной версии и выбор тарифа

## Контекст

Проект: Место Бизнес (коммерческая недвижимость). Стек: HTML, CSS, vanilla JS, Node.js + Express, PostgreSQL. Все стили в `public/styles.css`, разметка главной генерируется в `public/js/app.js`.

## Цель

1. Улучшить внешний вид стрелки рядом с надписью «Открыть каталог» и аналогичными ссылками на мобильных устройствах.
2. Сделать карточки тарифов кликабельными для выбора с плавной анимацией; нажатие кнопки «Оставить заявку» остаётся для отправки формы.

## Детали реализации

### 1. Стрелки на мобильных

**Проблема:** символ `↗` вставлен inline после текста ссылок. На мобильных он выглядит как «наклейка» из-за размера и отступов.

**Решение:**
- Заменить inline-символ `↗` на псевдоэлемент `::after` (или стилизованный span) с управляемым `font-size`, `line-height` и отступами.
- Для `.hero-link` и других похожих ссылок добавить единый класс `.arrow-link`, который формирует стрелку через `::after`.
- На мобильных (media query `max-width: 540px`) уменьшить размер стрелки до `16–18px` и выровнять по baseline текста.
- Убрать `aria-hidden="true"`-span из разметки, заменив на декоративный псевдоэлемент, который уже не читается скринридером.

### 2. Выбор тарифа

**Проблема:** сейчас карточки в `.pricing-grid` содержат только кнопку «Оставить заявку»; нет визуального выбора тарифа.

**Решение:**
- Для каждой `.pricing-card` добавить обработчик `click`, который:
  - убирает класс `selected` у всех карточек;
  - добавляет класс `selected` нажатой карточке;
  - сохраняет выбранный тариф, например, в `data-selected-tariff` на контейнере или в переменной.
- CSS:
  - переходы для `border-color`, `box-shadow`, `transform` длительностью `0.25s ease`;
  - `.pricing-card.selected` — более толстая/акцентная рамка, увеличенная тень, `transform: translateY(-4px)`;
  - `.pricing-card.selected.featured` — дополнительный лёгкий pulse/акцент для Премиум (например, `box-shadow` с цветом бренда);
  - при клике добавлять класс `selecting` с `@keyframes selectPulse` на 0.4s, после окончания класс убирается.
- Кнопка «Оставить заявку» остаётся неизменной и открывает модалку с тарифом из `data-tariff`.

## Файлы, которые затрагиваем

- `public/js/app.js` — разметка `.hero-link`, `.category-link`, `.city-link`, `.pricing-card`; добавление обработчиков выбора тарифа.
- `public/styles.css` — стили для `.arrow-link::after`, `.pricing-card.selected`, анимация `@keyframes selectPulse`, мобильные правки.

## Тестирование и публикация

- Вручную проверить вёрстку на мобильной ширине (< 540px) в devtools.
- Убедиться, что клик по карточке не мешает клику по кнопке внутри карточки.
- Запустить `npm test`.
- После прохождения тестов выполнить `git push` на GitHub.

## Критерии успеха

- На мобильных стрелка рядом с «Открыть каталог» выглядит аккуратно, не «наклеена».
- Карточка тарифа при клике выделяется анимацией; Премиум-тариф выделяется с заметной, но не агрессивной анимацией.
- Кнопка «Оставить заявку» продолжает открывать форму.
- Все тесты проходят; изменения отправлены в GitHub.
